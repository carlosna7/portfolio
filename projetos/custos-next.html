Custos Next

O Custos Next é a segunda versão do meu primeiro projeto em React, agora feito com Next.js. A aplicação simula a criação de projetos, cada um com um valor máximo de gastos definido na criação.

Esse valor máximo diminui conforme os serviços são adicionados. Foi desenvolvido com Next.js, JavaScript e Tailwind CSS, integrado a uma API em Node com banco MongoDB.
